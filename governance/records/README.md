# Records of procedures

Dated records of the procedures that the Compliance page checks by date (controls G8, H4, N4). One file per occasion, named
`<procedure>_YYYY-MM-DD.md`; the newest date decides whether the control is current.

| File name | Procedure | Every | Control |
| --- | --- | --- | --- |
| `internal_audit_YYYY-MM-DD.md` | Internal audit of the controls by someone not involved in the work | 3 months | G8 |
| `oversight_test_YYYY-MM-DD.md` | Oversight test with planted false alerts (`../oversight_test_protocol.md`) | 3 months | H4 |
| `incident_drill_YYYY-MM-DD.md` | Incident drill: a rehearsed wrong alert from retraction to closure (`../incident_procedure.md`) | 6 months | N4 |

Each record states: date, who took part, what was done, the numbers (for the oversight test: planted errors caught, true alerts dismissed, with a
95% Wilson interval; for the drill: minutes from retraction to closure), what failed, and the actions agreed. A record is never edited; a
correction is a new record.
